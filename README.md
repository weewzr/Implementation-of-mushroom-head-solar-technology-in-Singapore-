# 3-D Solar Geometry Optimisation for Land-Constrained Singapore

This repository is the canonical technical workspace for investigating mushroom-head, faceted, bifacial and topology-optimised photovoltaic geometries for Singapore.

The project reconstructs and formalises an exploratory research discussion into a reproducible engineering study. The central question is: **for a constrained horizontal footprint in Singapore, what three-dimensional PV geometry and movement strategy maximises useful annual solar-energy yield once optical, thermal, mechanical, structural and economic penalties are included?**

> Work in progress: the full technical report, derivations, computational model, figures, data provenance and bibliography are being added in the next project commit.
