# Foundation Record 01 — Originating Prompt

**Status:** Foundational project context  
**Purpose:** Preserve the question that generated the repository name and the original research direction.

## User prompt

> thinking about how to improve solar energy in the future in singapore due to land constraints
>
> would a mushroom head rotating solar panel work? or a sphere? could you calculate the best geometry to optimise the collection of sunlight, based on topology, plus any momentum factor that the solar panel should have to rotate

## Why this prompt remains important
This is the project's originating design question. It establishes five themes that must remain visible even as the model becomes more sophisticated:

1. Singapore's land constraint is the motivation.
2. The mushroom-head geometry is the founding architecture and source of the repository name.
3. A sphere is an explicit comparison geometry.
4. The user asked for topology/geometry optimisation rather than only conventional tilt optimisation.
5. The user explicitly raised rotation and momentum, which motivates the mechanical/actuation branch of the project.

Later work may reject or substantially modify any proposed geometry, but should not erase the research lineage represented here.
