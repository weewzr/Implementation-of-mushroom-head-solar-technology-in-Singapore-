# Data Provenance

## Authoritative Singapore context

The project currently uses the following verified public context:

- Energy Market Authority (EMA): average annual solar irradiance in Singapore is approximately **1,580 kWh/m²/year**.
- EMA (2 March 2026): Singapore achieved **2 GWp** installed solar capacity in 2025 and raised the 2030 deployment target to **3 GWp**. EMA also identifies innovative deployments including overhang solar and open-air car-park canopies.
- SERIS: the Singapore irradiance network contains **25 GHI stations** on approximately a 5 km × 5 km grid; **10** additionally measure global diffuse horizontal irradiance and meteorological variables. The system operates at **1-second temporal resolution**.

See `references/references.bib` for source URLs.

## Model-generated data

Outputs generated by `src/analysis/` are simulations and must be labelled as such. They are not measurements.

## Important unresolved input

A 57% diffuse share was used during exploratory conversation calculations. It remains a **provisional research input requiring direct source verification** before it may be treated as a formal model parameter. It should not be silently substituted for time-correlated DHI/GHI data.

## Intended final weather input

The validated model requires time-correlated values of at least:

- timestamp;
- GHI [W/m²];
- DHI [W/m²];
- DNI [W/m²] or a documented derivation method;
- ambient temperature [°C];
- wind speed [m/s];
- wind direction [deg].

Raw third-party datasets must not be committed unless redistribution rights permit it. If redistribution is not permitted, this directory will contain acquisition and preprocessing instructions instead.
